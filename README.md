# Student Sem-wise Skill Tracking System — Frontend

Technology: HTML5, CSS3, Vanilla JavaScript.

## Run
Open `index.html` in a browser. For best results use VS Code Live Server.

## Demo login
Enter any username and a password with at least 4 characters. Select Student, Faculty or Admin to open the corresponding dashboard.

## Frontend storage
Demo data is stored in browser localStorage.

## Backend-ready
`js/api.js` contains `API_BASE_URL = http://localhost:8080/api` and example REST endpoint mappings. These can later replace localStorage calls when Spring Boot + PostgreSQL is connected.

## Important
This is a frontend demonstration. Authentication, database persistence and real file uploads require the backend.

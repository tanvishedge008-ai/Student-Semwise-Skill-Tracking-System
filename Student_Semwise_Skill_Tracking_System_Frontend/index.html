About the System

The Student Sem-wise Skill Tracking System helps students maintain a structured record of skills, assessments, projects and verification across eight semesters. The frontend uses only HTML, CSS and Vanilla JavaScript and is designed to connect later with Spring Boot REST APIs and PostgreSQL.
